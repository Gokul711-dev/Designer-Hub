Based on a 16px root font size. Use these values for scalable typography in your designs.

Pixels (PX) REM Units Common Usage

20px 1.25rem Large Body / Small Headers

48px 3rem H1 Headers
64px 4rem Hero Title

Why REM?

Using REM (Root EM) ensures that your site's font scales relative to the user's browser settings. This is much better for accessibility than fixed Pixel values.
