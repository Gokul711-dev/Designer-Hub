Keyboard Reference

Essential Figma Shortcuts

Speed up your design workflow with these essential keyboard commands.

Basic Tools

  • V: Selection Tool
  • F: Frame Tool
  • R / L: Rectangle / Line
  • T: Text Tool
  • P: Pen Tool

Advanced Workflow

  • Shift + A: Add Auto-Layout
  • Alt + Drag: Duplicate
  • Ctrl + D: Duplicate in place
  • Shift + X: Swap Fill/Stroke

Organization

  • Ctrl + G: Group Selection
  • Ctrl + Alt + K: Create Component
  • Ctrl + Shift + O: Outline Stroke

Master the Big Nudge

Holding Shift + Arrow Keys moves elements by 10px (default) or 8px (if configured). This is the secret to perfect grid alignment.
