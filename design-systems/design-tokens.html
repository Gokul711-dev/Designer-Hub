Design Tokens: The Language of Systems

How to bridge the gap between design and development using semantic variables.

What are Design Tokens?

Design tokens are the visual atoms of a design system. They are name-value pairs that represent visual properties like colors, spacing, and typography. Instead of a hex code like `#6366f1`, you use a token like `color-primary-600`.

The Layer of Abstraction

By using tokens, you can change your entire brand color by updating a single variable value. This is crucial for multi-platform support (Web, iOS, Android) and themes (Light/Dark mode).

Naming Conventions

Don't name tokens after their values (e.g., `red`). Name them after their function (e.g., `text-error`). This is called Semantic Naming.

  • Global Tokens: Raw values (`color-blue-500`)
  • Alias/Semantic Tokens: Functional purpose (`button-primary-bg`)
  • Component-Specific Tokens: Tied to a component (`navbar-link-active`)

Pro Tools Tip

Figma's native "Variables" feature is the best way to manage tokens. It allows you to create aliases and export them directly to JSON for your dev team.
