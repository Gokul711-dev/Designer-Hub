The 8pt Grid System

Why developers love it, and how to use it to create perfectly balanced layouts.

What is it?

The 8pt grid system uses increments of 8 (8, 16, 24, 32, 40...) to define dimensions, padding, and margins of elements. By following this rule, you eliminate "random" spacing and ensure a logical hierarchy.

Why 8?

Most screen resolutions are divisible by 8. Using an 8pt grid makes scaling for different screen sizes (high-density displays) much cleaner, preventing half-pixel issues that cause blurring.

Hard Grid vs. Soft Grid

Hard Grid: Every element is placed on 8pt increments. This is common in print design.

Soft Grid: Individual elements can have any size, but the spacing between them must be in increments of 8. This is the industry standard for modern UI/UX.

Pro Spacing Tip

In Figma, set your "Big Nudge" to 8pt (Preferences > Nudge Amount). Now, holding Shift + Arrow keys will move elements exactly 8 pixels, keeping your grid perfect.
