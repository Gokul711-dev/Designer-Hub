Math-Based Typography Systems

How to use mathematical ratios to create harmonious font scales for any project.

The Power of the Scale

Typography shouldn't be arbitrary. To create a system that feels right, use a Modular Scale. You start with a base size (e.g., 16px) and multiply it by a ratio (e.g., 1.25 for a Major Third) to get your headings.

Common Ratios

  • 1.200 (Minor Third): Subtle, professional.
  • 1.250 (Major Third): Clear hierarchy, multi-purpose.
  • 1.414 (Augmented Fourth): Dramatic, editorial feel.

Accessibility (WCAG)

Typography isn't just about looking good; it's about being readable. Always ensure your body text has a contrast ratio of at least 4.5:1 against the background. For large text, 3:1 is acceptable.

Pro Handoff Tip

Always use REM units for code-readiness. A base of 16px means 1rem = 16px. Tools like the "CSS Unit Converter" in our cheatsheet silo can help you calculate this instantly.
